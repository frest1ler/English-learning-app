# English Learning App

Локальное настольное приложение для персонального изучения английского языка. Оно объединяет словарь, грамматические упражнения, интервальные повторения, адаптивные тренировки, диагностику уровня и необязательные AI-объяснения через локальную модель Qwen.

## Возможности

- занятие на сегодня длительностью 5, 10, 15 или 20 минут;
- словарь с транскрипциями, примерами, поиском и добавлением слов;
- интервальное повторение с оценками «Не помню», «Трудно», «Нормально», «Легко»;
- тесты EN → RU, RU → EN и смешанный режим;
- 1045 исходных грамматических упражнений по 9 темам;
- автоматический подбор заданий по уровню и слабым темам;
- режим без отображения грамматического времени до ответа;
- упражнения на перевод с русского на английский и смешанные тренировки;
- входная адаптивная диагностика на 30 вопросов;
- подробная статистика по словам, грамматике, периодам и типам ошибок;
- локальные AI-объяснения через Ollama и `qwen3:4b`;
- генерация слов и упражнений через Qwen с обязательным ручным подтверждением;
- AI-рекомендации новых лексических и грамматических направлений;
- библиотека материалов с поиском, CEFR-фильтрами и информацией об источнике;
- встроенные объяснения, если Ollama недоступна;
- светлая и тёмная темы;
- резервное копирование базы из интерфейса.

Регистрация и интернет для основной работы не нужны. Учебные данные и прогресс хранятся только на компьютере пользователя.

## Требования

- Python 3.10 или новее;
- Tkinter (обычно входит в Python);
- Ollama — необязательно, только для AI-объяснений.

Проект не требует сторонних Python-пакетов.

## Запуск

```bash
python3 main.py
```

При первом запуске приложение создаст `data_files/learning.db` и импортирует исходные TXT-файлы. Повторный запуск не дублирует данные.

## Локальные AI-объяснения

1. Установите Ollama с официального сайта.
2. Скачайте Qwen:

```bash
ollama pull qwen3:4b
```

3. Убедитесь, что Ollama запущена, и запустите приложение.

По умолчанию используется адрес `http://127.0.0.1:11434` и модель `qwen3:4b`. Название модели можно изменить во вкладке «Настройки».

После неправильного ответа нажмите «Объяснить ошибку». Запрос выполняется в фоновом потоке и не замораживает интерфейс. Если локальный API или модель недоступны, приложение автоматически покажет встроенное объяснение.

В заданиях RU → EN приложение сначала проверяет эталон локально. Если формулировка отличается, Qwen оценивает сохранение смысла и грамматику. Без Ollama используется строгая проверка по эталону.

## Расширение учебных материалов

Откройте вкладку «Материалы» и нажмите «Qwen»:

1. Выберите `word` или `exercise`.
2. Укажите тему, CEFR, количество и, для упражнений, тип задания.
3. Либо нажмите «Подобрать тему»: Qwen предложит направление по агрегированной статистике.
4. Запустите генерацию.
5. Просмотрите каждый кандидат и нажмите «Принять» или «Отклонить».

Сгенерированный контент никогда не попадает в тренировку автоматически. Сначала он сохраняется со статусом `pending`, проходит структурную проверку и требует ручного решения. Принятые слова добавляются в интервальное повторение, а упражнения — в адаптивный подбор. Источник и модель сохраняются в базе.

Поддерживаемые типы упражнений:

- `grammar_gap` — заполнение пропуска;
- `translation_ru_en` — перевод на английский;
- `find_tense` — определение времени;
- `correct_error` — исправление ошибки;
- `build_sentence` — составление предложения.

## Как работает персонализация

### Интервальное повторение

Для каждого слова сохраняются число повторений, интервал, коэффициент лёгкости и дата следующего показа. Ошибка возвращает слово через короткий интервал, успешные ответы постепенно увеличивают его.

### Умная тренировка

Приоритет упражнения зависит от освоения темы, давности последней практики, соответствия текущему CEFR-уровню, сложности и недавних показов этого задания.

Неподтверждённый AI-контент из подбора исключается. Алгоритм также чередует темы и типы упражнений. Qwen используется для предложения направлений и создания кандидатов, но не заменяет детерминированное расписание повторений.

### Диагностика

Тест начинается около A2 и меняет сложность после каждого ответа. Итоговый уровень и результаты по направлениям сохраняются локально и используются при формировании следующих тренировок. Это ориентировочная учебная оценка, а не официальный сертификат CEFR.

## Данные

Основная база: `data_files/learning.db`. В ней находятся слова, упражнения, тематические связи, очередь сгенерированного контента, решения модерации, история ответов, использование подсказок, интервальный прогресс, освоение тем, учебные сессии и настройки.

Исходные `words.txt`, `exercises.txt` и `rules.txt` используются для первичного наполнения. База и её служебные файлы исключены из Git. Резервную копию можно создать во вкладке «Настройки».

## Архитектура

```text
main.py
└── app.py                   главное окно и навигация
    ├── ui/                  вкладки и учебные окна
    ├── data/database.py     SQLite и репозитории
    ├── data/spaced_repetition.py
    ├── learning/            адаптация, диагностика, анализ ошибок
    ├── llm/providers.py     Ollama и встроенный fallback
    ├── llm/content_generator.py
    └── utils/helpers.py     нормализация и проверка ответов
```

Интерфейс не обращается к Qwen напрямую. `ExplanationService` выбирает провайдера, поэтому локальную модель можно заменить без изменения учебной логики.

## Тесты

```bash
python3 -m unittest discover -v
python3 -m compileall -q .
```

Тестами покрыты SQLite-импорт и миграции, резервное копирование, универсальные типы заданий, поиск материалов, модерация Qwen-контента, расписание повторений, адаптивный подбор, план занятия, диагностика, классификация ошибок, смысловая проверка перевода и обработка ответа Ollama.
